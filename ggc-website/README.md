# GGC website concept (2030 redesign)

A single-file, dependency-free concept site for Global Gateway Certifications Sdn Bhd.
Open `index.html` in a browser; no build step.

**Design:** ambient gradient mesh, glass surfaces, bento grid, big editorial type (Inter Tight + Instrument Serif), scroll reveals, light/dark themes with toggle, reduced-motion support, responsive down to 360px.

**Sections:** hero · schemes (MSPO, RSPO P&C, RSPO SCC, ISCC) · certificate lookup · process · pillars · mission & values · FAQ · contact.

**Placeholders to wire up before launch**
- Certificate lookup uses three sample records in the script. Connect it to the real certificate register.
- Contact form only validates locally. Connect it to an email or CRM backend.
- Office hours and FAQ timing wording are assumptions. Confirm them with GGC.
- Facts used (accreditation, schemes, RSPO geographic scope, address, phone, email) come from public RSPO/IAF listings.
